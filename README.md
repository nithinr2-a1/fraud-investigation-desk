# Fraud Investigation Desk

Open this folder in Visual Studio Code.

## Run
Because this project loads local CSV files, use a local web server.

Examples:
- VS Code Live Server extension
- python -m http.server 8000

Then open:
http://localhost:8000

Project structure:
- index.html
- css/style.css
- js/app.js
- assets/
- sample-data/
